# FocusFlow - 效率追踪器 v1.2.5 使用说明

## v1.2.5 更新亮点（已运行再次点击不再弹窗）

### 0. 已运行再次点击不再弹窗
- **调整**：程序已在运行时，再次双击**不再弹出"已在运行"的提示框**，而是**自动把已打开的窗口调到前台**，然后静默退出新起的进程（此前会重复弹出提示框）

### 1. 打包说明（单文件）
- 本版本采用**单文件(onefile)** 打包：对"下载即用"最稳定（文件夹模式会被 Windows 下载锁定标记拦截导致双击无反应）
- 说明：单文件运行时，任务管理器会出现**两个同名进程**（引导器 + 程序），这是单文件模式的正常现象，不影响使用

---

## v1.2.4 更新亮点（恢复单文件 · 下载即用）

### 0. 改回单文件打包（onefile）
- **原因**：v1.2.2 改用文件夹(onedir)后，从网页下载的压缩包解压出的 exe 和内部 DLL 都带"下载锁定标记(MOTW)"，Windows 会静默拦截，导致"双击没反应"，需手动解除锁定才能用
- **调整**：改回**单个 exe** 打包——单文件是把内部文件解压到临时目录运行，不受下载锁定标记影响，**下载解压后双击即可使用**，无需任何解除锁定操作
- 若首次运行 Windows 弹出安全提示，点击「更多信息 → 仍要运行」一次即可（之后不再提示）
- 说明：单文件运行时，任务管理器可能出现两个同名进程（引导器 + 程序），属正常现象

---

## v1.2.3 更新亮点（修复重复启动"无反应"）

### 0. 修复"双击没反应"
- **原因**：FocusFlow 只允许一个实例运行。当程序已在运行（如开机自启、托盘后台）时，再次双击会弹出一个可能被遮挡的"已经在运行"对话框，看起来像"没反应"
- **调整**：现在检测到已有实例时，会**自动把已打开的窗口调到前台**，并弹出置顶的清晰提示，不再让人误以为是启动失败
- 若需彻底重启，先在托盘图标右键选择「退出程序」

---

## v1.2.2 更新亮点（更流畅 · 更省内存 · 体积更小）

## v1.2.2 更新亮点（更流畅 · 更省内存 · 体积更小）

### 0. 打包方式改为文件夹模式（onedir）
- **原因**：旧版单文件(exe)每次启动都需把约 19MB 压缩包解压到临时目录，任务管理器会同时出现"引导器 + 程序"两个进程，启动慢、内存占用高
- **调整**：改用文件夹模式打包，运行只一个进程、无需临时解压，启动更快、内存占用更低
- **体积更小**：发布压缩包由约 19MB 降至约 14.5MB
- 运行方式：解压后双击 `FocusFlow\FocusFlow.exe`（整个文件夹需保持完整，勿单独移动 exe）

## v1.2.1 更新亮点（组合键按物理键独立计数）

### 0. 组合键不再合并为一次
- **问题**：按住 Ctrl（或 Ctrl+Shift）再按字母时，旧版会把该字母记成组合键名（如 `Ctrl+D`），看起来"组合键只算了一次"
- **调整**：现在每个物理键各自独立计数——按 `Ctrl+D` = `左Ctrl` 计 1 次 + `D` 计 1 次，Shift 同理（`Shift+D` = `Shift` + `D`）
- **历史数据迁移**：启动时自动扫描所有年度数据库，把已存在的 `Ctrl+A`~`Ctrl+Z`（及 `Ctrl+127`→`Delete`）记录改名为对应物理键，与新口径一致；同类计数自动合并，可放心升级

## v1.2.0 更新亮点（键鼠统计回归）

### 0. 按键排行 → 键鼠排行
- **重新启用鼠标统计**：在原有键盘统计基础上，新增鼠标操作统计（左键 / 右键 / 中键 / 侧键后退 / 侧键前进 / 滚轮上滑 / 滚轮下滑）
- **合并排行**：「按键排行」视图更名为「键鼠排行」，键盘与鼠标操作按次数统一排名、占比计算，分组统计新增「鼠标点击」「滚轮」两类
- **适配优化**：滚轮连续滚动自动合并计数——短时间（默认 0.8 秒）内同方向的连续滚动只计 1 次，方向切换或停顿后重新计数，避免"滑一会儿"被统计成十几次虚高
- **可配置**（`config.ini` 的 `[listener]` 节）：`mouse_enabled` 鼠标统计总开关（默认 true）/ `scroll_burst_window` 滚轮合并窗口秒数（默认 0.8）
- **联动**：今日活跃数、周期总数、趋势图、小时/星期分布、导出、番茄钟计数、护眼提醒均按"键鼠合并"口径统计；当前速度单位由「键/分」改为「次/分」
- 数据沿用现有 `key_log` 表（鼠标操作以名称区分），无需新建数据库表

### 0. 全局热键
- **调整**：全局热键 `Ctrl+Shift+F`（显示/隐藏主窗口）改为**默认关闭**
- **新增设置**：「设置」对话框新增"全局热键"选项：
  - 勾选「启用全局热键」后，Ctrl+Shift+F 才会显示/隐藏主窗口
  - 可自定义热键组合（Ctrl+Shift+F / Ctrl+Alt+F / Ctrl+Alt+Z / Ctrl+Shift+H / Alt+Shift+F）
  - 取消勾选即完全禁用，不影响其他功能

## v1.1.3 更新亮点（开机自启全程后台静默）

### 0. 开机自启后台静默
- **修复**：之前创建/读取启动快捷方式时会闪现 PowerShell 窗口（点开设置、勾选自启时）
- **调整**：所有 PowerShell 调用改为后台隐藏执行（CREATE_NO_WINDOW + -WindowStyle Hidden），全程静默，不影响使用
- 开机自启仍使用「启动文件夹」快捷方式：勾选=启用（任务管理器显示已启用），取消=移除

## v1.1.2 更新亮点（开机自启改为启动文件夹方式）

### 0. 开机自启方案调整
- **原因**：注册表 Run 键方式会被 Windows 11 的"启动应用"机制标记为「已禁用」，导致勾选后仍不生效
- **调整**：改为在「启动文件夹」创建快捷方式（shell:startup）
  - 勾选「开机自启」→ 创建 FocusFlow.lnk 快捷方式，任务管理器「启动应用」显示为「已启用」
  - 取消勾选 → 删除快捷方式，从「启动应用」中消失
  - 与用户直觉一致：勾选=启用，取消=不自启
- 自动清理旧版本残留的注册表启动项与禁用标记

## v1.1.1 更新亮点（修复开机自启）

### 0. 修复开机自启不生效
- **原因一**：Windows 11 的"启动应用"管理会将 Run 键启动项标记为「已禁用」，导致即使勾选了开机自启也不会自动启动
- **原因二**：开机自启命令带 `--hidden` 参数，旧版命令行解析将其当作未知参数直接退出，导致程序启动即闪退
- **修复**：
  - 启用开机自启时同步写入 `StartupApproved\Run` 的「已启用」标记，并校验 exe 路径
  - 命令行解析器兼容 `--hidden` 参数（隐藏启动到托盘，供开机自启使用）
- 若之前已勾选过开机自启，可在设置中先取消再重新勾选，或直接重新勾选即可生效

## v1.1 更新亮点（小憩与护眼 · 番茄工作法）

### 0. 小憩与护眼（自动弹窗休息）
- **自动检测高强度输入**：默认 30 分钟内按键超过 10000 次时，自动弹出**护眼提醒**
- **护眼提醒弹窗**：置顶显示"眼睛需要休息啦"，含 20 秒倒计时，可选择：
  - **「休息一下」**：关闭提醒；若番茄钟正在工作，自动切换到休息
  - **「继续工作」**：关闭提醒，继续记录
  - 倒计时结束未操作时自动关闭（视为继续工作）
- **防打扰机制**：提醒关闭后自动重置计数，且有冷却时间（默认 10 分钟）避免频繁弹出
- **可配置**（`config.ini` 的 `[rest]` 节）：`window_minutes` 检测窗口 / `key_threshold` 按键阈值 / `cooldown_minutes` 冷却时间 / `rest_seconds` 提醒倒计时 / `enabled` 总开关

### 1. 番茄工作法（计时器插件）
- 内置插件「番茄工作法」：在「插件管理」中双击或选中后点 [打开窗口]
- **工作/休息定时器**：默认工作 25 分钟、休息 5 分钟，后台秒级计时
- **按键统计联动**：工作时长内自动记录按键数，每个番茄钟的按键数据持久化保存
- **自动切换**：工作结束后自动进入休息（可勾选关闭）
- **今日汇总**：显示今日完成番茄钟数、总按键数、平均速度
- **历史记录**：最近 50 条番茄钟记录（类型/开始时间/实际时长/按键数）
- **时长自定义**：可调整工作时长与休息时长（1-120 分钟）
- 数据库保存在 `data/focusflow_pomodoro.db`

### 6. 按键统计优化（长按自动重复过滤）
- **修复**：玩游戏/长按某键时，系统自动重复事件导致按键数每秒增加几十次，严重虚高
- **方案**：按住期间重复触发的事件不再计数，只有真正"按下-释放"一次才算一次；即使 release 事件丢失也有 15 秒兜底，不影响后续计数
- **可配置**：`config.ini` 的 `[listener] ignore_key_repeat`（默认 true）可开关，`key_repeat_stale_seconds`（默认 15）可调整兜底时长

### 7. 新增"清除今日按键"功能
- **背景**：本次优化只阻止新的长按虚高；之前已经产生的今日虚高数据需要手动清除
- **入口**：「设置」对话框中"清除今日键鼠"；或在"键鼠排行"表格中右键键鼠 → "清除该键鼠今日次数"
- **用法**：选中（或输入）某个键鼠名（如 A、空格、回车、Esc、鼠标左键、滚轮上滑），确认后仅删除该键鼠今天的记录，不影响历史和其他键鼠，同时重置今日计数与实时速度

### 8. 稳定性与流畅性优化
- **修复界面卡顿**：后台全量刷新时不再阻塞等待数据库写入（原先每次可能卡 0~2 秒）
- **修复 flush 残留 bug**：写入队列为空时请求刷新，事件不再残留导致后续"等待 2 秒超时"
- **清除操作后台执行**：删除按键数据在后台线程完成，界面不卡顿，完成后自动刷新

### 9. 记账本优化
- **收支记录按 ID 排序**：列表改为按记录 ID 降序排列，最新添加的记录在最上面
- **分页布局优化**：表格行数随窗口高度自适应，分页栏紧贴表格下方且始终可见，无需下拉整个界面；消除记录下方大片空白
- **恢复"距今多久"功能**：操作栏新增"距今多久"按钮，支持多选记录（Ctrl/Shift 多选），按"X年Y天"显示每条的距今时间（按记录名称显示）
- **修复月度汇总分类明细**：分类明细现按净值统计（收入为正、支出为负），同分类收入 500 + 支出 500 显示为 0.00，不再错误累加成 1000
- **分页固定每 10 条**：收支记录列表每页固定显示 10 条
- **日期范围筛选生效**：筛选栏的"从/到"日期现在真正参与查询

### 10. 移除鼠标统计（重大变更，v1.2 已恢复）
- **说明**：本节的"纯键盘统计"调整仅对 v1.0 历史版本有效；v1.2.0 起已重新启用键鼠统计（见文首更新亮点），鼠标点击/滚轮与键盘按键统一合并统计

### 11. 悬浮窗优化
- **尺寸缩减**：宽度由 120px 缩减至 80px（减少 1/3）
- **配色优化**：背景改为淡青色 (#E0F4F4)，字体改为黑色，更柔和护眼

### 12. 数据库健壮性增强
- **连接超时**：SQLite 连接 timeout 由 10s 提升至 15s，busy_timeout 由 10s 提升至 15s

### 13. 记账本（重大优化）
- **修复筛选 bug**：选择"全部"现在会查询全部记录，而不是把表格清空（修复了 radio button value=None 导致 SQL 变成 WHERE type='None' 的隐性 bug）
- **新增分类筛选**：可在筛选栏直接选择"分类"和"细分分类"进行筛选，下拉框选择即触发查询
- **新增关键词筛选**：支持按物品名/备注/分类/细分分类模糊搜索

- **新增重置筛选**：一键清空所有筛选条件
- **分类层级修正**：梦幻西游现在正确地放在"游戏"分类下作为细分分类，不再出现在顶级分类

### 14. 定时任务（重大优化）
- **新增间隔执行类型**：例如"每天 7:00-23:00 期间每 60 分钟执行一次"，格式 HH:MM-HH:MM|分钟数
- **新增任务编辑功能**：选中任务后点击"✎ 编辑"，或双击任务即可修改（不再只能删除后重新添加）
- **新增启用/禁用切换**：一键切换任务的启用状态，无需删除
- **新增调度校验**：保存前自动校验时间格式，避免保存错误配置

## 功能介绍

FocusFlow 是一款个人效率与专注力分析工具，通过记录键盘与鼠标活跃数据，帮助您了解自己的打字习惯、鼠标操作与工作节奏。

### 核心功能
- 实时记录键盘与鼠标活跃次数（左/右/中键、侧键、滚轮）
- 统计每个按键/鼠标操作次数及占比排行（键鼠排行）
- 按键分组统计（字母/数字/功能键/修饰键/编辑键/鼠标点击/滚轮/其他）
- 多时间维度查看：今日 / 7天 / 15天 / 30天 / 1年 / 总计
- 年度数据归档与查询
- 历史日期查询（指定某一天的统计）
- 实时操作速度（CPM，每分钟键鼠操作次数）
- 趋势图表（近 7 天/30 天活跃趋势折线图）
- 暂停/恢复记录（隐私保护）
- 开机自启（开机后台静默运行）
- 关闭窗口自动最小化到系统托盘

### 小憩与护眼（v1.1）
- 检测连续高强度输入（默认 30 分钟 10000 键），自动弹出护眼提醒
- 20 秒倒计时提醒，可选「休息一下」或「继续工作」
- 提醒冷却机制，避免频繁打扰（`[rest]` 配置可调）

### 番茄工作法（v1.1）
- 内置插件「番茄工作法」：工作/休息定时器（默认 25 分钟工作 + 5 分钟休息）
- 每个番茄钟自动记录按键数，与统计联动
- 今日完成番茄钟数 / 总按键 / 平均速度汇总
- 最近 50 条番茄钟历史记录
- 工作结束后可自动进入休息

### 数据管理
- 年度归档：每年数据独立存储（data/focusflow_YYYY.db），自动控制文件大小
- 数据导出：CSV / HTML
- 清理旧数据：按保留天数删除
- 数据库压缩：VACUUM 回收空间
- 自动备份：退出时备份到 backup/ 目录（保留最近 5 个）
- 数据完全本地存储，不上传任何信息

### 记账本功能（v1.0）
- 记录收入和支出
- 按日期/月/年/全部/类型/分类/细分分类/关键词多条件查询
- 分页查询（每页 10 条）
- 计算距今多久（年+天，支持多选）
- 分类盈亏统计（如游戏投入/赚取）
- 双击或点击按钮修改记录
- 分类数据可通过"记账本数据维护"插件自由维护

### 定时任务功能（v1.0）
- 三种调度类型：
  • 每日定时（HH:MM）
  • 一次性（YYYY-MM-DD HH:MM）
  • 每日间隔执行（HH:MM-HH:MM|分钟数）
- 启用/禁用切换
- 选中后双击或点击"编辑"修改任务
- 后台线程检查，到点自动执行

### 插件系统功能（v1.0）
- 动态加载/卸载/重载/删除/编辑插件
- 热加载：自动检测文件变更并重载
- 选中插件后显示其界面
- 内置"记账本数据维护"插件
- 内置"番茄工作法"插件（v1.1）

### 体验增强
- 全局热键 Ctrl+Shift+F 显示/隐藏主窗口（默认关闭，可在设置中开启并自定义）
- 悬浮窗（画中画）：置顶小窗口实时显示今日活跃和速度
- 系统托盘：悬停显示"今日活跃 X 次 | 速度 XX 次/分"，暂停时图标变灰
- 亮色/暗色主题切换
- 现代化界面设计（Windows 11 风格）
- 首次启动提示可关闭（"不再显示"）

## 打包生成 exe（首次使用）

### 一键打包
1. 确保已安装 Python 3.8 或更高版本
   - 下载地址：https://www.python.org/downloads/
   - 安装时务必勾选 "Add Python to PATH"
2. 双击运行 `build.bat`
3. 等待打包完成，exe 文件在 `dist` 文件夹中

### 打包说明
- `build.bat` 优先使用 `FocusFlow.spec` 配置文件打包（推荐）
- 若 spec 失败，自动回退到命令行模式（含所有 hidden-import）
- 打包前会自动清理 build/ 和 dist/ 目录

### 打包后报错排查
如果 exe 运行时弹出 "No module named 'xxx'" 错误：
1. 确认所有 .py 文件都在同一目录
2. 重新运行 build.bat（会自动清理重建）
3. 若仍失败，手动执行：`pyinstaller --noconfirm FocusFlow.spec`
4. 查看控制台输出的错误信息

## 在新电脑上部署（免安装）

**直接用软件包即可运行，无需安装任何环境：**

## 使用方法

### 启动程序
双击 `FocusFlow.exe` 运行，程序启动后自动开始记录。
首次启动会弹出使用提示（可勾选"不再显示"）。

### 查看统计
- 顶部显示今日活跃次数和实时速度
- 点击统计周期按钮切换（今日/7天/15天/30天/1年/总计）
- 年度下拉框可选择查看历史年度数据
- 在日期输入框中输入 YYYY-MM-DD 格式日期，点击"查询"可查看指定日期
- 点击"今天"按钮回到今日统计
- 表格显示键鼠排行（排名、键鼠、次数、占比）
- 切换到"分组统计"标签页可查看按键分组汇总
- 切换到"趋势图"标签页可查看近 7/30 天活跃趋势

### 记账本使用（v1.0）
- 在视图下拉框中选择"记账本"
- 点击"➕ 添加记录"添加收入/支出
- 在筛选栏选择类型/分类/细分分类，或输入关键词进行筛选
- 选中一条记录后点击"✎ 修改选中"，或直接双击记录即可修改
- 选中后点击"删除选中"可批量删除（支持多选）
- 点击"距今多久"查看选中记录距今多久
- 点击"分类盈亏"查看各分类的盈亏统计
- 点击"查询"进行按日期/月份/年份/关键词查询

### 定时任务使用（v1.0）
- 在视图下拉框中选择"定时任务"
- 点击"➕ 添加任务"添加任务
- 选择调度类型：
  • 每日定时：每天指定时间执行（如 08:30）
  • 一次性：指定日期时间执行一次（如 2026-12-31 23:59）
  • 每日间隔执行：每天指定时间段内每隔 N 分钟执行一次
    （如 07:00-23:00|60 表示每天 7~23 点每 60 分钟一次）
- 选中任务后双击或点击"✎ 编辑"修改
- 点击"启用/禁用"切换任务状态
- 点击"删除选中"删除任务

### 插件管理使用（v1.0）
- 在视图下拉框中选择"插件管理"
- 点击"新建插件"创建插件模板（会生成 .py 文件，需编辑后生效）
- 选中插件后可执行：
  • 加载：加载未加载的插件
  • 卸载：卸载已加载的插件
  • 热重载：手动重载插件（用于修改后立即生效）
  • 编辑：用系统默认编辑器打开插件 .py 文件
  • 删除：卸载并删除插件 .py 文件（不可恢复）
- 勾选"启用插件热加载"后，修改/新增插件文件会自动重载
- 选中已加载的插件后，下方会显示插件提供的界面

### 记账本数据维护插件（v1.0）
- 在"插件管理"视图中加载"记账本数据维护"插件
- 选中后下方显示该插件的界面
- 左栏操作分类：
  • 类型筛选：全部/支出/收入/双向
  • 添加/修改/删除分类
  • 上移/下移调整排序
- 右栏操作细分分类：
  • 先在左栏选中一个分类
  • 然后 添加/修改/删除 该分类下的细分分类
- 修改分类名会自动同步更新所有相关记账记录
- 删除分类不会影响已存在的记账记录（保留 category 字符串）

### 暂停记录
- 打开「设置」对话框（头像旁"设置"按钮），勾选/取消"暂停记录"；或右键托盘菜单选择"暂停记录"
- 暂停时托盘图标变灰，底部显示 [已暂停] 标识
- 暂停期间不会记录任何按键（隐私保护）

### 最小化到托盘
- 点击窗口右上角 X 关闭按钮 = 最小化到托盘，程序后台继续运行
- 也可以打开「设置」→"隐藏到托盘"
- 双击托盘图标 或 右键→"显示统计面板" 可恢复窗口
- 全局热键（Ctrl+Shift+F，默认关闭）也可显示/隐藏窗口，可在「设置」中开启并自定义

### 开机自启
- 打开「设置」对话框（头像旁"设置"按钮），勾选"开机自启"
- 开机后程序自动后台启动，不弹窗口，仅在托盘显示图标
- 再次取消勾选即可关闭

### 启动时直接进入托盘
- 打开「设置」对话框，勾选"启动时直接进入托盘（不显示主窗口）"
- 开启后，软件启动不显示主界面窗口，只在系统托盘后台运行（悬浮窗仍会自动显示）

### 完全退出程序
- 右键点击系统托盘图标 → 选择"退出程序"
- 退出时会自动：刷新待写入数据 → 备份数据库 → 释放资源

## 插件开发指南

### 最简插件模板
```python
# -*- coding: utf-8 -*-
PLUGIN_NAME = "我的插件"
PLUGIN_DESC = "插件描述"
PLUGIN_VERSION = "1.0"
PLUGIN_AUTHOR = "作者"

def init():
    """插件初始化（可选）"""
    pass

def get_view(parent):
    """返回插件界面（可选）"""
    import tkinter as tk
    from tkinter import ttk
    frame = ttk.Frame(parent)
    ttk.Label(frame, text="Hello from 插件").pack(pady=20)
    return frame

def cleanup():
    """插件清理（可选）"""
    pass
```

### 插件开发要点
- 文件放在 `plugins/` 目录下，文件名建议用英文（如 `my_plugin.py`）
- 必须定义 `PLUGIN_NAME`、`PLUGIN_DESC`、`PLUGIN_VERSION`
- 可选实现 `init()`、`get_view(parent)`、`cleanup()`
- `get_view(parent)` 接收父容器，返回 ttk.Frame
- 开启热加载后，修改文件保存即自动重载
- 出错不会影响其他插件和主程序

## 配置文件说明（config.ini）

首次运行自动生成，可用文本编辑器修改：

```ini
[database]
batch_size = 100              ; 批量写入阈值
flush_interval = 30           ; 定时刷新间隔（秒）
backup_on_exit = true         ; 退出时自动备份
max_backups = 5               ; 最大备份数
auto_vacuum_days = 7          ; 每 N 天自动 VACUUM（0=禁用）
yearly_archive = true         ; 启用年度归档

[stats]
cpm_window = 60               ; CPM 计算窗口（秒）
today_count_cache_ttl = 10    ; 今日计数缓存有效期（秒）

[listener]
ignore_modifier_keys = false  ; 是否忽略修饰键
ignore_function_keys = false  ; 是否忽略 F1-F12

[gui]
refresh_interval = 2          ; 增量刷新间隔（秒）
full_refresh_interval = 30    ; 全量刷新间隔（秒）
show_first_run_tip = true     ; 是否显示首次提示
theme = light                 ; light / dark

[hotkey]
enabled = false                ; 是否启用全局热键（默认关闭，可在设置中开启）
toggle_window = ctrl+shift+f  ; 显示/隐藏主窗口热键

[floating]
enabled = false               ; 启动时是否显示悬浮窗
opacity = 0.85                ; 透明度 0.1-1.0
```

## 注意事项

1. 本工具仅用于统计个人键盘使用情况，请在自己的电脑上使用
2. 部分安全软件可能报毒（键盘 Hook 机制），添加信任即可
3. 如需卸载：先取消开机自启 → 右键托盘退出程序 → 删除文件
4. 数据库损坏时，可从 backup/ 目录恢复
5. 日志文件位于 logs/ 目录，排查问题时可参考
6. 年度数据库位于 data/ 目录，可按需备份或迁移
7. 首次启动会自动迁移旧版分类数据到新表，原有记账记录不受影响
